# ScreenPenPlus
在整个屏幕上进行涂画（Draw on the screen）

大概是为了简洁，工具条上只有8个按钮：操，笔，擦，撤，重，清，设，保
代码行数：六百左右

**操：** 操作（正常操作计算机，但程序不会退出。⚠这会清空所有痕迹）
**笔：** 画笔（让鼠标在屏幕上涂画。）
**擦：** 擦除（鼠标拖动以擦除之前留下的痕迹。）
**撤：** 撤销（返回上一步操作。）
**重：** 重做（重新进行撤销的操作。）
**清：** 清空（清空屏幕上的所有痕迹。）
**设：** 设置（弹出一个菜单，选择颜色、粗细等。）
**保：** 保存（弹出文件保存选择框，保存当前屏幕图像）

### **⚠注意：**
1. 这个工具是防止屏幕截图的（避免截取到自己）
2. uiaccesstools.exe只是用来提权到uiaccess作为更高级的置顶方法。不提供源代码。在程序是py源代码时禁用。
3. 笔的快捷键是"p"，擦的快捷键是"e"。
4. 程序部分由AI生成。
5. 程序最不足的地方在于，设置是由一个菜单进行，弹出在工具条左上角。

### 用到的python库
- os
- subprocess
- sys

这两个用于**提权**至uiaccess。

- math

用于计算绘画轨道。

- sys
- PyQt6

用于实现界面（sys用途真广，但毕竟有QApplication(sys.argv)）。

- ctypes

用于实现防截图。

大部分时标准库，但需要：
```
pip install PyQt6
```
慢的话：
